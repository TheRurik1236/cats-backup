# Резервное копирование картинок с котами

Программа берёт картинку кота с нужным текстом с сайта
[cataas.com](https://cataas.com) и сохраняет её в папку на Яндекс.Диске.
Картинка загружается на диск по ссылке, на компьютер она не скачивается.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Программа попросит ввести:

1. текст для картинки — он же станет названием файла;
2. токен с [Полигона Яндекс.Диска](https://yandex.ru/dev/disk/poligon/).

## Результат

- на Яндекс.Диске в папке с названием группы появится картинка;
- рядом с программой появится `result.json` с размером загруженного файла:

```json
[
  {
    "file_name": "hello.jpeg",
    "size": 90420
  }
]
```
